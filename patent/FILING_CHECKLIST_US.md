# United States Filing Checklist

Official starting point: [USPTO Provisional Application for Patent](https://www.uspto.gov/patents/basics/apply/provisional-application)

This checklist is procedural guidance, not legal advice.

## A. Immediate provisional filing

### Documents

- [ ] `US_PROVISIONAL_SPECIFICATION_DRAFT.md`, reviewed for accuracy and converted to PDF.
- [ ] `PATENT_DRAWINGS.html`, exported as black-and-white PDF drawing sheets.
- [ ] USPTO provisional cover sheet PTO/SB/16 or an Application Data Sheet containing equivalent information.
- [ ] Basic provisional filing fee at the applicant's verified entity status.
- [ ] Optional claim appendix (`US_CLAIMS_DRAFT.md`) included to strengthen written-description support.

### Information that must be completed

- [ ] Exact title.
- [ ] Full legal name and residence of every actual inventor.
- [ ] Confirm each named inventor made a conception contribution to at least one claimed feature.
- [ ] Applicant/assignee identity and ownership basis.
- [ ] Correspondence address.
- [ ] Attorney/agent docket number if represented.
- [ ] Government-interest statement.
- [ ] Entity status (large, small, or micro) verified, not assumed.

### Technical quality checks

- [ ] Every feature likely to be claimed in a later application is fully described now.
- [ ] Best mode known to each inventor is disclosed.
- [ ] At least one enabled implementation is disclosed for every claimed functional result.
- [ ] Alternative implementations are described without relying solely on means-plus-function language.
- [ ] Drawings support every important structural and process relationship.
- [ ] No unsupported promise of closed-loop furnace control; the implementation is read-only advisory.
- [ ] The public EVRAZ dataset is identified as `public_reference`, not the applicant's plant and not live.

### Filing

- [ ] File through USPTO Patent Center.
- [ ] Save the Electronic Acknowledgement Receipt and application number.
- [ ] Record the provisional filing date and exact 12-month nonprovisional/PCT deadline.
- [ ] Use “Patent Pending” only after obtaining a filing receipt.

## B. US nonprovisional filing within 12 months

- [ ] Specification compliant with 35 U.S.C. 112(a).
- [ ] Claims compliant with 35 U.S.C. 112(b); target 20 total and no more than 3 independent unless fees are accepted.
- [ ] Abstract (150 words or fewer).
- [ ] Drawings compliant with 37 C.F.R. 1.84.
- [ ] Application Data Sheet claiming benefit of the provisional by application number and filing date.
- [ ] Inventor oath/declaration (PTO/AIA/01 or appropriate form).
- [ ] Assignment documents if ownership is transferred.
- [ ] Information Disclosure Statement listing known patents, papers, manuals, and public disclosures.
- [ ] Specification and claims reviewed against 35 U.S.C. 101, 102, 103, and 112.
- [ ] Consider PCT filing before the same 12-month priority deadline.

## C. Public-disclosure and foreign-rights warning

- Public repository and website publication occurred on **10 November 2026**.
- USPTO states that an inventor-originated disclosure can fall within the AIA one-year grace period, but foreign rights can be lost.
- The US deadline should not be treated as permission to delay. File promptly.
- Preserve exact copies, timestamps, commit hashes, and ownership of the public disclosure.
- Do not assume the disclosure came from all inventors. Counsel must map authorship and derivation.

## D. Items not required in a provisional

- Formal claims are not required, although including draft claims can improve support.
- An oath/declaration is not required.
- An Information Disclosure Statement should not be filed in the provisional because it is not examined.
